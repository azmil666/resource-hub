# Cloudflare

## Why Use It

Web applications face distributed DDoS attacks, malicious bot scraping, and international latency bottlenecks without a dedicated edge proxy network. Cloudflare operates an authoritative global anycast network that provides enterprise-grade DDoS mitigation, Web Application Firewall (WAF) filtering, and intelligent edge caching. It acts as a resilient front door for internet properties, protecting origin infrastructure while accelerating static and dynamic asset delivery.

## Key Capabilities

- Industry-leading Anycast DNS network delivering ultra-fast domain resolution and automatic failover
- Comprehensive Edge CDN with granular page rules, Brotli compression, and tiered caching
- Advanced security suite featuring automated DDoS mitigation, managed WAF rule sets, and bot management
- Modern Zero Trust access controls, SSL/TLS encryption management, and HTTP/3 support out of the box

## Stack Fit & Workflow

The fundamental networking, security, and edge acceleration layer for any web infrastructure, whether hosted on AWS, GCP, Vercel, or bare-metal servers.
