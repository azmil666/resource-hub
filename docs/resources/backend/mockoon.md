# Mockoon

## Why Use It

Setting up realistic API mocks for frontend testing or third-party service simulation often requires maintaining cloud subscriptions or writing custom Express scripts. Mockoon is a free, open-source desktop and CLI application that allows developers to mock RESTful APIs locally in seconds without writing a line of backend code. It provides complete control over HTTP status codes, headers, response delays, and dynamic templating rules.

## Key Capabilities

- Visual desktop GUI for designing mock endpoints, route rules, response headers, and status codes
- Dynamic templating engine supporting faker data generation, regex routing, and conditional rules
- Headless CLI (@mockoon/cli) for running mock servers in CI/CD test pipelines and containerized environments
- Local-first architecture with zero account requirements, cloud sync lock-in, or telemetry data leaks

## Stack Fit & Workflow

Essential for frontend and QA engineers building web or mobile apps, running integration tests, or simulating external microservices.
