# Bang Motion

## Why Use It

Frontend developers frequently spend hours fine-tuning bezier curves, keyframes, and exit transitions to make UI animations feel cohesive. Bang Motion is a specialized skill for Claude Code and agent CLI frameworks that provides codified motion design principles, spring physics formulas, and ready-to-inject animation snippets. It gives AI coding agents the design sensibility required to write refined animations.

## Key Capabilities

- Codified easing scales and spring presets for micro-interactions, modal reveals, and page transitions
- Automated transition review and timing refinement commands for existing CSS and Tailwind codebases
- Frame-rate optimized transition curves that prevent layout thrashing and composite layer repaints
- Direct compatibility with standard web primitives, Framer Motion, and Tailwind CSS animations

## Stack Fit

Use Bang Motion when collaborating with AI coding agents to polish UI animations, elevate landing page motion, or tokenize transitions across a design system.
