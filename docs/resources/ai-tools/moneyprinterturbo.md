# MoneyPrinterTurbo

## Overview

MoneyPrinterTurbo is an open-source tool that automates the end-to-end creation of HD short videos—from script writing and voice synthesis to video footage assembly and subtitle burning.

## Useful for

- Automating batch short-form video creation for TikTok, YouTube, and Reels
- End-to-end text-to-video automation using open LLMs and media sources
- Studying automated programmatic media composition workflows
