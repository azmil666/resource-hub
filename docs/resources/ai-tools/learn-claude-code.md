# Learn Claude Code

## Why Use It

Understanding how commercial coding agents execute bash commands, manage file state, and resolve context loops requires dissecting complex internal architectures. Learn Claude Code provides a comprehensive, 17-lesson hands-on guide demonstrating how to build an autonomous coding agent harness from first principles. It strips away proprietary magic to show exactly how agentic loops, tool definitions, and context management work under the hood.

## Key Capabilities

- 17 structured engineering lessons progressing from basic tool-calling to full terminal-driven coding agents
- Concrete code examples implementing agent loops, file editing, bash execution, and error recovery
- Deep-dive explanations into context window optimization, subagent delegation, and tool sandboxing
- Practical blueprints for integrating Anthropic Claude models and the Model Context Protocol (MCP)

## Stack Fit & Workflow

Essential for AI engineers, systems developers, and tooling architects building custom internal coding assistants or evaluating agent architectures.
