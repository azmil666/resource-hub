# Groq

## Why Use It

Traditional GPU-based LLM inference suffers from memory bandwidth bottlenecks, leading to sluggish time-to-first-token and slow throughput that degrades interactive agent experiences. Groq bypasses standard GPU architectures using its custom Language Processing Unit (LPU), executing open-weight models at deterministic, ultra-high speeds exceeding 500 tokens per second. It eliminates latency bottlenecks for real-time voice agents, live chatbots, and multi-step tool-calling workflows.

## Key Capabilities

- Unmatched token generation speeds enabling real-time conversational agents and sub-second reasoning loops
- Strict OpenAI-compatible REST API endpoints allowing drop-in replacement across existing codebases and SDKs
- First-class support for top open-weight models including Llama 3, Mixtral, and Gemma
- Dedicated function calling, JSON mode, and structured outputs at wire speed

## Stack Fit & Workflow

Best suited for real-time conversational agents, voice AI pipelines, and agentic workflows built on LangChain, Vercel AI SDK, or custom HTTP clients.
