# Shoogle.dev

## Why Use It

The shadcn/ui component ecosystem is highly decentralized across hundreds of independent registries, making it hard to find specialized blocks, navigation menus, and form templates. Shoogle.dev aggregates over 500 community shadcn/ui registries into a single searchable directory with interactive live previews. Crucially, it provides a dedicated Model Context Protocol (MCP) server that lets AI coding agents in Cursor, VS Code, or Claude Code search and install components directly from prompt context.

## Key Capabilities

- Comprehensive index of 500+ community shadcn/ui blocks, design kits, and independent registry endpoints
- Native Model Context Protocol (MCP) server enabling direct component discovery and installation inside IDEs
- Interactive component previews with instant copy-paste CLI installation commands
- Semantic search filtering by category, framework compatibility, and component style variants

## Stack Fit & Workflow

Pairs directly with modern React, Next.js, and Tailwind CSS projects using shadcn/ui, especially inside AI-assisted IDEs like Cursor and Claude Code.
