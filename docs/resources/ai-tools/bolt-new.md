# Bolt.new

## Why Use It

Most AI coding generators either output isolated code snippets or run in disconnected cloud sandboxes that lack native Node.js environments. Bolt.new, built by StackBlitz on WebContainers, runs a full-featured Node.js runtime entirely in the browser, allowing an AI agent to install npm packages, spin up dev servers, and fix terminal errors in real time. It delivers a complete full-stack development environment directly inside a browser tab.

## Key Capabilities

- In-browser full-stack execution powered by WebContainers with true npm package installation
- Autonomous AI agent capable of multi-file editing, debugging build errors, and dependency resolution
- Live browser preview with hot-module reloading and devtools console inspection
- Direct deployment to Netlify and one-click GitHub repository export

## Stack Fit

The gold standard for interactive full-stack web app generation, live component experimentation, and zero-setup debugging in Vite, Next.js, and Svelte.
