# Windsurf

## Why Use It

Traditional IDE AI plugins operate with isolated prompt context, forcing developers to manually coordinate file references, terminal outputs, and multi-file refactoring steps. Windsurf is an agentic AI-powered IDE built on a native VS Code fork featuring Cascade, an autonomous coding agent deeply integrated into workspace state, terminal executions, and file systems. It maintains persistent context across complex multi-step refactors, autonomously executing shell commands and debugging errors in real time.

## Key Capabilities

- Cascade agentic engine performing multi-file edits, running compiler commands, and validating test suites autonomously
- Deep semantic codebase indexing combining AST analysis, git history, and symbol graphs for precise code grounding
- Real-time collaborative flow where the agent and developer edit files concurrently without context collisions
- Full compatibility with VS Code extensions, keybindings, and development containers

## Stack Fit & Workflow

The primary IDE environment for software engineers across full-stack TypeScript, Python, Go, Rust, and C++ codebases seeking autonomous agent pair-programming.
