# Floorplan

## Overview

Floorplan analyzes your repository and draws an interactive, plain-English architectural map showing how files, routes, state, and databases connect.

## Useful for

- Visualizing complex codebases during developer onboarding
- Generating readable architectural diagrams directly from source code
- Tracing data flow across full-stack applications with AI
