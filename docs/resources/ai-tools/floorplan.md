# Floorplan

## Why Use It

Complex codebases often overwhelm developers during onboarding because raw directory trees fail to convey runtime architecture, data flow, and dependency boundaries. Floorplan statically analyzes source trees with LLMs (such as Claude or Codex) to generate an interactive, plain-English architectural map of an application. It provides engineers with instant spatial intuition of route hierarchies, state management boundaries, and persistence layers.

## Key Capabilities

- Automated repository parsing extracting architectural topologies, route maps, and data schemas
- Interactive browser-based visualization rendered as an intuitive spatial diagram
- Plain-English summarization of component responsibilities and service boundaries
- Minimal setup requiring only repository access and an AI model API key or agent harness

## Stack Fit & Workflow

Pairs effectively with modern full-stack web architectures (Next.js, Remix, Rails, Express) during team onboarding, architecture reviews, and legacy refactoring workflows.
