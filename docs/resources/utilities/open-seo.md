# Open SEO

## Overview

Open SEO provides an open-source technical SEO auditing toolkit, competitor backlink tracker, and keyword research environment.

## Useful for

- Auditing website performance, metadata, and core web vitals
- Self-hosting an alternative to expensive SEO enterprise suites
- Extracting and monitoring keyword rankings programmatically
