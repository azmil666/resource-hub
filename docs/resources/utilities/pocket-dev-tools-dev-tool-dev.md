# Pocket Dev Tools (dev-tool.dev)

## Why Use It

Using ad-heavy online converters for basic tasks like base64 encoding, JSON formatting, or image compression exposes sensitive tokens, source code, and payload data to untrusted third-party servers. Pocket Dev Tools is a privacy-first, zero-installation browser workspace that executes dozens of developer utilities locally on the client using WebAssembly and native Web APIs. It ensures that uploaded files, cryptographic keys, and sensitive JSON payloads never leave the browser.

## Key Capabilities

- 100% client-side local execution powered by WebAssembly, Web Workers, and HTML5 APIs with zero server telemetry
- Comprehensive developer suite: JSON formatters, JWT decoders, regex testers, UUID generators, and base64 encoders
- Media processing utilities: client-side image compression, SVG optimization, audio trimming, and PDF merging
- Offline-ready Progressive Web App (PWA) functionality allowing offline developer execution without an active internet connection

## Stack Fit & Workflow

A secure, daily desktop companion for security-conscious software engineers, backend developers, and DevOps teams needing quick data transformations.
