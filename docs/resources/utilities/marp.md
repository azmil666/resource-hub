# Marp

## Why Use It

Traditional presentation tools decouple slide content from developer workflows, preventing version control, automated CI rendering, and simple styling customizations. Marp is a modern slide authoring toolchain that converts plain Markdown files into clean, responsive HTML, PDF, or PowerPoint presentations using standard CSS themes. It brings Git-driven workflows and declarative design to technical slide decks.

## Key Capabilities

- Declarative Markdown slide authoring with simple page breaks, directives, and header/footer configurations
- Modular CSS theming system supporting custom CSS rules, scoped slide styles, and background image directives
- Flexible export toolchains: Marp CLI (@marp-team/marp-cli) for headless PDF/PPTX/HTML generation, and a dedicated VS Code extension
- Built-in syntax highlighting for code blocks and KaTeX support for mathematical equations

## Stack Fit & Workflow

Pairs with VS Code, Git, and GitHub Actions CI pipelines for technical presenters, software architects, and conference speakers authoring slide decks in Markdown.
