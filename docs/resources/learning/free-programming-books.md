# Free Programming Books

## Why Use It

High-quality technical textbooks and educational materials can be prohibitively expensive for self-taught developers, students, and engineers in developing economies. Free Programming Books (maintained by the EbookFoundation) is one of the most starred repositories on GitHub, curating thousands of legally free programming books, interactive tutorials, podcasts, and cheat sheets across virtually every programming language. It serves as an open global library for continuous software engineering education.

## Key Capabilities

- Thousands of legally free, open-access technical books categorized by programming language, operating system, and topic
- Curated collections of free interactive courses, coding podcasts, cheat sheets, and technical video tutorials
- Multi-language directory translated into over 30 natural languages by a global open-source community
- Rigorous curation standards ensuring only verified legal and actively accessible links are indexed

## Stack Fit & Workflow

An indispensable lifelong learning companion for self-taught developers, university students, and senior engineers researching new languages and technical disciplines.
