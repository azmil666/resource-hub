# TypeScript - Programming with Mosh

## Why Use It

Developers moving from dynamically typed JavaScript to TypeScript often struggle with initial compiler configuration, type annotations, and compiler errors. Programming with Mosh provides a clear, high-density video tutorial that cuts through academic jargon to teach practical TypeScript syntax and project setup in under an hour. It focuses on the 20% of TypeScript features that developers use in 80% of daily programming workflows.

## Key Capabilities

- Rapid zero-fluff introduction to core primitives, arrays, tuples, enums, functions, and object typing
- Clear explanations of advanced types: type aliases, unions, intersections, literal types, and optional chaining
- Step-by-step setup guide for configuring tsconfig.json, source maps, and the TypeScript compiler (tsc)
- Practical debugging tips demonstrating how static typing eliminates common runtime TypeError bugs

## Stack Fit & Workflow

Ideal crash course for JavaScript developers, React engineers, and Node.js programmers transitioning into TypeScript-based codebases.
