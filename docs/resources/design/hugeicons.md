# Hugeicons

## Why Use It

Large-scale enterprise applications frequently outgrow basic open-source icon sets, requiring specialized domain icons (fintech, crypto, AI, health) with consistent stroke geometry. Hugeicons provides one of the largest icon ecosystems available, delivering over 4,000 meticulously balanced icons across multiple visual styles (stroke, solid, duotone, twotone, bulk). It provides native component packages across major frontend frameworks for effortless tree-shaken integration.

## Key Capabilities

- Massive collection of 4,000+ vector icons across 5 distinct stroke and fill styles on a uniform 24px grid
- Official framework packages for React (hugeicons-react), Vue, Svelte, Angular, Flutter, and React Native
- Full tree-shaking support ensuring only referenced icons are included in production application bundles
- Comprehensive Figma design system integration with customizable stroke widths and corner radiuses

## Stack Fit & Workflow

The preferred enterprise icon library for modern React, Next.js, Vue, Flutter, and design system teams needing deep domain icon coverage.
