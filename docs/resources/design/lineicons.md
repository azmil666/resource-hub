# Lineicons

## Why Use It

Inconsistent icon scaling and missing responsive stroke weights can break typographic alignment in dense data tables and enterprise navigation trees. Lineicons is an engineered vector icon system featuring over 8,400 icons handcrafted on standard 16px, 20px, and 24px grids to ensure crisp pixel-aligned rendering. It provides modular delivery via web fonts, SVG symbols, and framework components with clean semantic HTML.

## Key Capabilities

- Extensive library of 8,400+ icons spanning line, solid, and duotone styles designed for pixel-perfect clarity
- Pixel-grid alignment optimized for 16px, 20px, and 24px target sizes to prevent subpixel antialiasing blur
- Multiple delivery methods: SVG sprites, CSS web fonts, npm component packages, and CDN scripts
- Dedicated categorization for modern SaaS, e-commerce, cloud architecture, and development tooling

## Stack Fit & Workflow

Pairs effectively with Bootstrap, Tailwind CSS, React, and Vue applications in enterprise SaaS, e-commerce, and admin dashboards.
