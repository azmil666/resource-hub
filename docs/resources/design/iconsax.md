# Iconsax

## Why Use It

Designing cohesive multi-platform applications often requires switching between outlined, filled, and duotone states for active and inactive navigation tabs. Iconsax provides an expansive collection of over 6,000 icons meticulously crafted across 6 distinct visual styles (linear, bold, bulk, outline, two-tone, broken). It ensures that mobile and web interfaces maintain identical geometric form factors regardless of active styling state.

## Key Capabilities

- 6 distinct visual rendering styles per icon: Linear, Bold, Outline, Two-tone, Bulk, and Broken
- Comprehensive coverage spanning 1,000+ unique conceptual icons across 30+ functional application domains
- Framework packages available for Flutter, React, Vue, and native mobile development
- Dedicated Figma component libraries with instant variant switching between style states

## Stack Fit & Workflow

Best suited for mobile app development (Flutter, React Native) and modern web dashboards requiring interactive icon state variants.
