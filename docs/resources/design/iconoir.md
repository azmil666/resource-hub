# Iconoir

## Why Use It

Many icon libraries suffer from inconsistent visual weights, uneven bounding boxes, or locked proprietary licenses that restrict enterprise use. Iconoir is a completely free, open-source library of over 1,500 meticulously crafted SVG icons designed on a uniform 24px grid with consistent 1.5px strokes. It offers zero-dependency packages for every major web and mobile framework, making it a reliable drop-in standard for production applications.

## Key Capabilities

- Over 1,500 consistent, minimalist vector icons with uniform visual weighting and clear geometric alignment
- Official framework packages for React, React Native, Vue, Svelte, Angular, and CSS web font fallbacks
- Full tree-shaking support and tiny package size ensuring minimal bundle overhead
- Direct Figma community library, Framer plugin, and Raycast extension for rapid designer-developer handoffs

## Stack Fit & Workflow

Ideal for React, Next.js, Vue, and Svelte developers building clean, modern design systems and SaaS dashboards.
