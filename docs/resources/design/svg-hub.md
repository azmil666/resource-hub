# SVG Hub

## Why Use It

Adding playful decorative elements like hand-drawn underlines, squiggles, and arrows to marketing copy often results in bloated third-party illustration packages. SVG Hub is a lightweight collection of over 70 handcrafted vector squiggles, scribbles, and geometric shapes built specifically for web developers. It allows users to customize stroke weights and hex colors in the browser and copy clean, optimized inline SVG code with a single click.

## Key Capabilities

- 70+ curated vector squiggles, hand-drawn underlines, expressive arrows, and geometric markers
- Interactive color picker and stroke customization updating SVG markup in real time
- One-click copy for clean, minified inline SVG code with zero unneeded metadata or bloated namespaces
- Lightweight DOM impact allowing seamless embedding inside React JSX, Vue templates, or HTML strings

## Stack Fit & Workflow

Perfect for marketing websites, landing pages, and developer documentation built with Tailwind CSS, Next.js, and Astro.
