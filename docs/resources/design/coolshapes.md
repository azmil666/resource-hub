# Coolshapes

## Why Use It

Crafting trendy, abstract visual accents with noise textures and soft mesh gradients requires complex SVG filter chains and heavy graphic design workflows. Coolshapes provides a curated collection of 100+ abstract geometric shapes styled with organic grainy gradients and retro noise aesthetics. It delivers these assets as ready-to-use React components, standalone SVGs, and high-resolution PNGs for immediate frontend use.

## Key Capabilities

- Over 100 unique abstract shapes categorized into stars, polygons, organic blobs, and geometric glyphs
- Authentic grainy gradient aesthetic generated with SVG feTurbulence and feColorMatrix noise filters
- Native React component package (coolshapes-react) with prop-driven color and dimension controls
- Dedicated Figma plugin and clean SVG exports for seamless designer-to-developer asset handoffs

## Stack Fit & Workflow

Ideal for design engineers and frontend developers building expressive marketing pages, product showcases, and web applications with React, Next.js, and Tailwind CSS.
