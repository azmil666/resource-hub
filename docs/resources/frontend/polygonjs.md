# Polygonjs

## Overview

Polygonjs is a procedural node-based WebGL design tool inspired by Houdini that lets developers create interactive 3D particle systems and animations without writing complex shaders from scratch.

## Useful for

- Creating procedural 3D visual effects and interactive landing page backgrounds
- Exporting interactive 3D scenes as lightweight JavaScript bundles
- Building complex particle simulations and reactive WebGL animations
