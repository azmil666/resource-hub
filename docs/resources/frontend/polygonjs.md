# Polygonjs

## Why Use It

Authoring complex procedural 3D animations, particle simulations, and dynamic WebGL shaders in code requires advanced linear algebra and GLSL expertise. Polygonjs is a node-based visual procedural 3D animation and shader tool that exports clean, embeddable WebGL/Three.js code directly to web projects. It empowers creative coders and frontend developers to design intricate procedural 3D effects visually while maintaining full programmatic control via JavaScript APIs.

## Key Capabilities

- Visual node-based procedural modeling, particle dynamics, and GLSL shader graph construction
- Direct export to standard npm packages and lightweight Three.js modules with zero proprietary runtime lock-in
- Programmatic JavaScript/TypeScript API enabling dynamic runtime parameter modulation based on user input
- Seamless integration with modern web bundlers (Vite, Webpack) and frontend frameworks (React, Vue)

## Stack Fit & Workflow

Best suited for creative developers, design technologists, and marketing site engineers building interactive Three.js 3D landing pages and WebGL hero visuals.
