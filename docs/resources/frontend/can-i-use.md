# Can I Use

## Why Use It

Deploying modern web features (like CSS Grid, subgrid, View Transitions, or WebAssembly) without cross-browser compatibility verification risks breaking experiences for millions of users on legacy or mobile engines. Can I Use is the definitive global browser compatibility matrix detailing support status for modern HTML, CSS, SVG, and JavaScript web APIs across desktop and mobile browsers. It enables engineers to make data-driven decisions on feature adoption and polyfill requirements.

## Key Capabilities

- Exhaustive compatibility tables for hundreds of web specifications tracking Chrome, Safari, Firefox, Edge, and mobile browsers
- Global and regional browser usage share data powered by StatCounter to evaluate true audience impact
- Granular tracking of feature flags, prefixed implementations, and known browser-specific bugs
- Integration with build-time developer tooling via the browserslist npm package used by Babel, PostCSS, and Autoprefixer

## Stack Fit & Workflow

The foundational reference tool for frontend developers, QA engineers, and automated build pipelines configuring PostCSS, Babel, and Lightning CSS.
