# Remotion

## Overview

Remotion is a developer framework that leverages React and web standards to author and render deterministic, programmatic MP4 videos.

## Useful for

- Generating dynamic, personalized videos from code and APIs
- Building programmatic video ads, summaries, and social media shorts
- Automating animated web graphics and data visualizations
