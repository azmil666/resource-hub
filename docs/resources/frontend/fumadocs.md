# Fumadocs

## Why Use It

Building beautiful, performant documentation portals within modern Next.js App Router applications typically requires cobbling together MDX parsers, syntax highlighters, and search indexes. Fumadocs is an open-source documentation framework built natively for Next.js that delivers instant full-text search, automatic table of contents generation, type-safe navigation, and pre-styled UI components. It integrates directly into existing Next.js repositories without running a separate documentation site engine.

## Key Capabilities

- Native Next.js App Router support with full React Server Component (RSC) optimization and streaming
- Built-in full-text search engine (FlexSearch / Orama) delivering sub-millisecond local documentation search
- Automated sidebar and navigation tree generation derived from local filesystem MDX or remote CMS sources
- Rich interactive MDX components: tabs, callouts, code blocks with syntax highlighting, and API playground wrappers

## Stack Fit & Workflow

The premier documentation framework for Next.js, React, and Tailwind CSS projects needing integrated, high-performance docs.
