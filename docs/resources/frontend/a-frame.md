# A-Frame

## Overview

A-Frame is an open-source WebXR framework maintained by Supermedium and Mozilla that wraps Three.js into declarative custom HTML elements, making 3D and VR scene construction as simple as web markup.

## Useful for

- Building WebXR and VR browser experiences using standard HTML syntax
- Prototyping 3D spatial environments for headsets and mobile screens
- Integrating 3D entities, cameras, and physics with standard DOM APIs
