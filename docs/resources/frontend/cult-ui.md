# Cult UI

## Why Use It

Standard component libraries often provide functional UI primitives but lack the expressive motion, tactile physics, and micro-interactions required for world-class SaaS applications. Cult UI is an open-source registry of over 150 animated, accessible React components built on top of shadcn/ui and Framer Motion. It empowers design engineers to install high-craft UI components (shimmer buttons, fluid text reveals, magnetic dock bars) into their projects via simple CLI commands.

## Key Capabilities

- Over 150 animated React components built with Tailwind CSS, Radix UI primitives, and Framer Motion
- shadcn/ui-compatible registry allowing direct CLI installation (npx shadcn add) with full source code ownership
- Highly expressive interaction patterns: text scrambles, fluid card tilts, glowing badges, and spring modals
- Fully accessible keyboard navigation and ARIA role compliance inherited from underlying Radix primitives

## Stack Fit & Workflow

Built specifically for design engineers and frontend developers building Next.js, React, and Tailwind CSS applications requiring exceptional craft and motion.
