# Cult UI

## Overview

Cult UI is an open-source registry of sophisticated, animated React components built with Tailwind CSS and Framer Motion, ready to copy-paste into shadcn/ui apps.

## Useful for

- Adding high-end micro-interactions, animated borders, and text effects to React apps
- Expanding shadcn/ui with creative design engineering components
- Building memorable SaaS landing pages and interfaces
