# Vengeance UI

## Why Use It

Adding futuristic animations, neon borders, and kinetic button interactions to web applications often requires tedious custom CSS keyframing and SVG path manipulation. Vengeance UI is an open-source component library providing bold, animated React components, glowing buttons, futuristic loaders, and kinetic text blocks. It equips developers with high-energy visual elements designed to make web interfaces feel alive and tactile.

## Key Capabilities

- Curated set of expressive React components: magnetic buttons, glowing borders, glitch texts, and cybernetic loaders
- Copy-paste architecture allowing developers to inspect and own component source code without package bloat
- Built on top of Tailwind CSS and Framer Motion for responsive scaling and customizable spring physics
- Clean component interfaces with intuitive props for colors, animation speeds, and trigger states

## Stack Fit & Workflow

Pairs with Next.js, React, and Tailwind CSS for gaming websites, AI dashboards, developer tool portals, and creative portfolios.
