# It's All Widgets!

## Why Use It

Evaluating whether the Flutter framework is capable of handling complex production requirements often leads to skepticism regarding desktop performance, web responsiveness, and native hardware integration. It's All Widgets! is the definitive open-source community directory showcasing thousands of production apps built with Flutter across iOS, Android, macOS, Windows, Linux, and the web. It allows developers to verify real-world architectural capabilities, open-source code repositories, and app store listings.

## Key Capabilities

- Searchable showcase of thousands of verified production Flutter apps spanning fintech, enterprise tools, and games
- Direct links to App Store, Google Play, web builds, and open-source GitHub source repositories where available
- Categorized taxonomy filtering apps by industry vertical, platform target, and state management architecture
- Open submission process enabling the global Flutter community to register and showcase new applications

## Stack Fit & Workflow

Indispensable reference for engineering leadership, mobile architects, and Flutter developers validating cross-platform viability and discovering open-source Flutter implementations.
