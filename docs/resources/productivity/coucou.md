# Coucou

## Why Use It

Transferring large log files, database dumps, and build artifacts between developer machines or remote servers often requires awkward third-party cloud uploads or fragile SCP commands. Coucou is a minimalist, developer-focused file-sharing utility that enables direct, encrypted peer-to-peer file transfers and instant technical collaboration from the terminal. It eliminates intermediary cloud storage latency and maintains strict end-to-end transfer security.

## Key Capabilities

- High-speed peer-to-peer file transfers bypassing cloud storage bandwidth bottlenecks and upload quotas
- End-to-end cryptographic encryption ensuring private, zero-knowledge data transmission between nodes
- Minimalist command-line interface designed for rapid piping of file streams and build artifacts
- Cross-platform support across macOS, Linux, and Windows terminal environments

## Stack Fit & Workflow

A valuable terminal utility for DevOps engineers, systems administrators, and distributed engineering teams sharing large binary artifacts and logs.
