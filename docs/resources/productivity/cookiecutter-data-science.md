# Cookiecutter Data Science

## Why Use It

Data science repositories often devolve into tangled messes of unnumbered Jupyter notebooks, scattered CSV files, and undocumented dependencies that cannot be reproduced by team members. Cookiecutter Data Science provides an opinionated, standardized directory structure and project scaffolding template designed specifically for reproducible data science. It establishes clear boundaries between raw immutable data, processed features, exploratory notebooks, and production model code.

## Key Capabilities

- Standardized directory layout separating raw data, processed datasets, models, reports, and source code
- Built-in data immutability conventions ensuring raw data is never overwritten or edited in place
- Automated environment and dependency management integrating with Conda, pip-tools, and Makefile automation
- Modular Python source package structure enabling clean imports into notebooks and production deployment scripts

## Stack Fit & Workflow

The standard project boilerplate for data scientists, machine learning engineers, and quantitative researchers working with Python, Conda, and Jupyter.
