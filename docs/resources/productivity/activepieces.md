# Activepieces

## Why Use It

Proprietary SaaS integration platforms (like Zapier and Make) charge steep per-task fees, enforce closed runtime environments, and lock workflow data on third-party clouds. Activepieces is an open-source, self-hostable workflow automation platform featuring a clean visual builder and code-first TypeScript extensibility. It allows engineering teams to automate multi-step business workflows, sync CRM data, and connect internal APIs without vendor lock-in or recurring per-task costs.

## Key Capabilities

- Visual flowchart builder combined with code-first TypeScript piece authoring with npm package support
- 200+ pre-built integration connectors for leading SaaS platforms, databases, AI models, and communication tools
- Fully self-hostable via Docker and Kubernetes with complete data sovereignty and zero telemetry leaks
- Modern API, webhook triggers, queue workers, and enterprise role-based access control (RBAC)

## Stack Fit & Workflow

The preferred open-source automation engine for developers, IT engineers, and privacy-conscious teams deployed alongside Docker and Node.js.
